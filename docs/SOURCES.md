# Sources

Every course document this project draws on, where it came from, and whether a copy is kept here. All files were retrieved on 2025-12-07 and are stored unchanged under [`source/`](source). HTML pages are the raw HTML returned by `curl` with a browser User-Agent; images, scripts and stylesheets they reference were not downloaded, so the saved pages may look unstyled when opened locally.

The project specification itself is [`assignment.md`](assignment.md). It was written for this project and adapts the course tasks listed below.

**These copies are for private reference only.** The course material belongs to the universities and instructors named here. Remove `docs/source/` before this repository is made public, and link to the original URLs instead.

## Notes

- **CMU 16-868 title.** The current course page calls 16-868 "Legged Systems" (fall, 12 units, final project on "a legged mobility problem of their own choosing"). The past student report calls the same course number "Biomechanics & Motor Control". Both names are kept as found.
- **Past student work.** The CMU report is kept because it describes the original drop-foot task (tibialis anterior reduced to 33% of 800 N, CMA-ES re-optimization of 32 reflex parameters). It contains no code. No student code from any course is used in this repository.
- **Georgia Tech ME 6409 term.** The PDF header reads "Spring 2026" although the URL contains "Fall 2026". The PDF text is treated as authoritative.
- **Stanford Lab 1.** In the Spring 2018 offering the same exercise was "Lab 0 (done in ME 281)"; in Spring 2023 it is Lab 1. The Spring 2018 page is <https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/pages/53087509/BIOE-ME+485+Spring+2018>.
- **Software and data** used by the project (SCONE, its tutorial models, the Camargo et al. dataset) are described in [`../data/README.md`](../data/README.md), not here.
